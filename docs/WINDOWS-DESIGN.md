# Windows desktop design contract

The Codestra professional workstation profile favors legibility and low visual noise.

- Medium contained photography at 70 percent of available screen space.
- Dark neutral margins, a subtle shadow, and a one-pixel frame.
- No image stretching and no forced crop.
- Dark shell and app surfaces with transparency where Windows supports it.
- Centered taskbar with secondary controls hidden.
- Social applications grouped instead of scattered across the desktop.
- User files are never bulk-moved or deleted.
- Ordinary HKCU preferences and Windows Task Scheduler are used; Explorer binaries are never patched.
