# Codestra Workstation

Reusable, idempotent workstation configuration for Codestra Windows machines.

The Windows professional profile provides:
- dark Windows and app theme with transparency;
- centered taskbar with Search, Task View, Widgets, Chat, and Copilot buttons hidden;
- compact File Explorer, file extensions visible, and This PC as the launch surface;
- medium-fit 70 percent centered framed photo wallpaper with no crop or stretch;
- 15-minute wallpaper rotation;
- 24-hour secure idle lock;
- 24-hour display timeout and no automatic standby;
- a consistent 14-app Social Apps folder and Start Menu group;
- preservation of unrelated desktop files and existing non-canonical shortcuts.

Install with the elevated Install-CodestraProfessionalDesktop.ps1 script and verify with Verify-CodestraProfessionalDesktop.ps1. The scripts are safe to rerun.
